# Dictionary source and licensing

The `words.txt` wordlist included in BENBOMB was filtered from
[first20hours/google-10000-english: 20k.txt](https://github.com/first20hours/google-10000-english/blob/master/20k.txt).

Original source notice, reproduced for clarity:

> Data files are derived from the *Google Web Trillion Word Corpus*, as described by Thorsten Brants and Alex Franz, and distributed by the Linguistic Data Consortium. Subsets were distributed by Peter Norvig. Corpus editing and cleanup by Josh Kaufman.

The upstream [LICENSE.md](https://github.com/first20hours/google-10000-english/blob/master/LICENSE.md) permits educational/personal/research use, but cautions against commercial use without LDC licensing.

Filtered changes: only lowercase alphabetical tokens of 3–20 letters retained and duplicates removed. BENBOMB contains 19,404 words. Replace it with an independently licensed dictionary before using this project commercially.
